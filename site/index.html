midi-agent-console 固件一键刷写

线协议 v2：心跳看门狗、锁存急停、舵机限位和转速上限、DRIVE 到点自动停。

1. 用 USB 线连上 ESP32 或 ESP32-C3 SuperMini。

2. 点下面的按钮，选串口，等它写完（会先擦除整片 flash）。

这个浏览器不支持网页串口，请用电脑上的 Chrome 或 Edge（需要 HTTPS）。 页面需要通过 HTTPS 打开。

接线（和固件里的引脚一致）：

  • ESP32 DevKitC：舵机 18 / 19；TB6612 PWMA 25、AIN1 26、AIN2 27、PWMB 14、BIN1 33、BIN2 13；STBY 接 3.3V。
  • ESP32-C3 SuperMini：舵机 0 / 1；PWMA 3、AIN1 4、AIN2 5、PWMB 10、BIN1 6、BIN2 7；STBY 接 3.3V。
  • 舵机用单独的 5V 供电，所有地接在一起，舵机旁边并一个 470µF 电容。

固件已在 Uno / ESP32 / ESP32-C3 上编译通过，还没在真车上跑过。不要接门锁、继电器、电源这类东西。
